## 文档维护规则

维护主题文档时遵循以下规则：

- **同步更新**：接口、配置、端口、服务职责、数据存储或用户流程发生变化时，同步更新对应主题文档。
- **内容完整**：说明正式设计、模块与接口、异常和安全边界及验证方式。
- **事实准确**：以仓库代码、配置、数据库脚本和测试为事实来源，不记录未经代码验证的能力。
- **信息安全**：不记录迭代过程、路线图、真实密钥、默认密码或个人数据。
- **结构清晰**：一个段落表达一个中心意思；并列的职责、规则、流程、异常和验证项使用列表或表格。
- **图表兼容**：优先使用兼容低版本 Mermaid 的 `graph LR` 和基础 `sequenceDiagram`，复杂流程拆分表达。
- **提交检查**：提交前校验 Markdown 格式、Mermaid 语法和仓库内链接。
