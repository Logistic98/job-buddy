# Goal: 以练习记录为主线重构练习台

## 目标

练习台默认展示可继续和可复盘的练习记录，并以一个明确的“创建练习”入口打开智能组卷或规则组卷。用户点击记录或完成组卷后直接进入练习，题库中的行内单题练习不污染记录列表。

## 验收标准

1. 练习台首页以练习记录为主体，展示全部、进行中、已完成数量，并支持搜索和状态筛选。
2. 每条记录显示练习名称、时间、题数、练习模式、组卷方式和当前结果，提供继续练习或查看复盘以及删除操作。
3. 删除前必须二次确认；删除失败保留记录和弹窗错误，删除成功立即从列表移除。
4. 练习台使用单一“创建练习”主按钮，智能组卷和规则组卷在同一弹窗中切换，创建成功直接进入练习。
5. 练习详情提供“练习记录”和“创建练习”操作；返回记录首页不清空当前页面会话答案，切换到其他练习或创建新练习前提示未提交答案风险。
6. 题库行内单题练习以 `recorded=false` 创建，可正常作答与提交，但 `GET /api/interview/practices` 不返回该练习。
7. `DELETE /api/interview/practices/{examId}` 只能删除当前租户和用户所属练习，并级联清理练习题目关系。
8. 前端定向测试、Backend 练习接口测试、Flyway 检查和对应 Quick Gate 通过。
9. 本地启动页面，在浏览器验证记录首页、创建弹窗、打开记录、返回列表和删除确认。

## 停止条件

- 不改变智能组卷 Runtime 的候选披露和选题白名单边界。
- 不修改既有 Flyway 基线，只追加更高版本迁移。
- 不把未提交答案扩展为跨会话持久化。
- 不修改与练习中心无关的页面或业务数据。
